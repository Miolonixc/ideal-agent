# Changelog

## 0.2.8 — unreleased

- Android-компаньон: светлая/тёмная тема с сохранением выбора и улучшенная
  доступность управления генерацией.
- MCP manifest с capabilities и подтверждение первого подключения в TUI.
- Необязательные агрегатные локальные метрики без сохранения сообщений,
  вложений, ключей, ID сессий и сетевых данных.
- Подготовлен подписанный Android release workflow: версия берётся из тега
  `vX.Y.Z`, публикуются APK, SHA-256 и SBOM.

## 0.2.0 — 2026-08-11

- Безопасное обновление установки для Termux, Linux и macOS.
- Устойчивые провайдеры: нормализованные ошибки и retry временных HTTP-сбоев.
- Изолированная память по workspace, sandbox-проверки и защищённый HTTP-канал.
- Расширенный TUI: настройки, модули, вложения, скриншоты и адаптация для Termux.
- Явное доверие и capabilities для skills/MCP, лимиты MCP и cancellation.
- Диагностика `/health`, `/audit` и `--dry-run`.
